# 时序图分阶段详细分析（供报告使用）

## 一、资产负债率（Lev）2000‑2024 分阶段分析

### 阶段 1：2000‑2005 年：持续上行，杠杆快速扩张
**趋势：** 均值逐年走高，杠杆持续攀升。
**核心因素：** 入世后经济高速增长、房地产行业爆发、银行信贷宽松；企业大规模举债扩产，主动加杠杆。

### 阶段 2：2006‑2010 年：高位回落
**趋势：** 均值从 2006 年起掉头下行，杠杆进入去化通道。
- 2006‑2007：股权分置改革完成，IPO/再融资重启，企业转向股权融资降杠杆；央行信贷收紧
- 2008‑2010：金融危机冲击加速去杠杆，企业主动收缩负债

### 阶段 3：2011‑2016 年：持续回落，回归健康区间
**趋势：** 均值、中位数持续走低至 42%–45%。
- 四万亿红利消退、产能过剩
- 2015 年供给侧改革启动，强制去杠杆
- 中位数降幅大于均值，中小企业去杠杆更明显

### 阶段 4：2017‑2024 年：低位稳健震荡
**趋势：** 长期稳定在 42%–45% 区间。
- 经营趋于保守，不盲目加杠杆
- 贸易摩擦、疫情、地产下行等外部冲击下保持稳健
- 均值始终高于中位数，右偏结构稳定

## 二、总资产收益率（ROA）& 现金比率（Cash）2000‑2024 分阶段分析

### 阶段 1：2000‑2007 年：同涨同跌，2005 年同步暴跌触底
**趋势：** 高度同步。2005 年跌至全周期最低，之后同步回升。
- 2005：A 股历史大熊市（上证 998 点），盈利崩盘、现金流枯竭
- 2006‑2007：股权分置改革、牛市，盈利改善、现金增加

### 阶段 2：2008‑2010 年：短期冲击后暴涨，2010 年双指标见顶
**趋势：** 2008 年短暂下跌后快速上行，2010 年同步达到历史峰值。
- 金融危机短期冲击盈利
- 四万亿刺激政策推动盈利爆发、现金囤积

### 阶段 3：2011‑2015 年：盈利下行，现金消耗
**趋势：** ROA 持续走低，Cash 大幅跳水。
- 四万亿退潮、产能过剩
- 企业进入偿债周期，消耗现金
- 2015 年供给侧改革启动加速盈利探底

### 阶段 4：2016‑2019 年：ROA 反弹，Cash 回升
**趋势：** ROA 修复上行，Cash 同步抬升。
- 供给侧改革见效，上游涨价修复利润
- 2018 年中美贸易战推动企业囤现避险

### 阶段 5：2019‑2022 年：走势分化
**趋势：** ROA 下行，Cash 逆势走高。
- 2020 年疫情冲击，盈利暴跌
- 企业"现金为王"，囤积现金避险
- 最经典的反向分化段：盈利越差、现金越多

### 阶段 6：2022‑2024 年：双双回落
- 地产下行、内需疲软
- 企业消耗前期囤积的现金维持运营
- 宏观预期偏弱，盈利与现金双弱
